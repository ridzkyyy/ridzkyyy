## What I'm building

**[MCP Lab](https://github.com/ridzkyyy/mcp-lab)** — Postman for MCP servers. Connect to any Model Context Protocol server from the browser, browse its tools, run them from a schema-generated form, and read formatted results. [Try it live](https://mcp-lab.vercel.app).

[![MCP Lab demo](https://raw.githubusercontent.com/ridzkyyy/mcp-lab/main/docs/demo.gif)](https://mcp-lab.vercel.app)

**[fleet-mcp](https://github.com/ridzkyyy/fleet-mcp)** — a fleet telemetry MCP server: GPS positions, trips, geofences, and NMEA parsing for AI agents. Ships with a zero-setup simulated demo fleet, so you can point an agent at real-looking telemetry in one command. It's also the kind of server MCP Lab was built to test.
